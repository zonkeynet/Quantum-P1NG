How to use your map in Q‑Geo ▾
  1. Select an area and choose Prepare offline map.
  2. Run the generated command on a computer with the PMTiles tool installed and internet access.
  3. Transfer the .pmtiles file to your phone and import it from Q‑Geo → Offline maps.
  4. Choose the offline map source in Q‑Geo. Vector maps work without downloading tiles; this preview’s satellite imagery is not included.

01 / RECOMMENDED FOR Q‑GEO

Create your PMTiles map

Extract your area from a published Protomaps version 4 build into a standalone .pmtiles vector map (Zoom 0–15). Satellite imagery and the selected display theme are not included. Run the command on a computer with the PMTiles tool installed.

pmtiles extract https://build.protomaps.com/...

Open Protomaps published maps and choose a version 4 build date. The publisher limits automatic lookups from other websites.
