နားထောင်မည့် လမ်းကြောင်း ရွေးပါ
ကမ္ဘာလုံး တစ်ခု။
 တံခါး နှစ်ပေါက်။
ဌာနကို စာရင်းသွင်းခြင်းနှင့် ၎င်း၏ အသံကို web သို့ ဖွင့်ပေးခြင်းသည် သီးခြား ရွေးချယ်မှုများ ဖြစ်သည်။

      

        
WEB
မည်သည့် ဘရောက်ဆာတွင်မဆို
ထည့်သွင်းရန် မလို။ public web အသံ ပေးသော ဌာနများကို ဖွင့်ပါ။ Relay နှင့် stream provider များက သင့် IP လိပ်စာကို မြင်သည်။

        
TOR
Tor မှတစ်ဆင့်
Q-P1NG တွင် Tor ပေါ်မှ သို့မဟုတ် Tor Browser ရှိ ဌာန၏ onion စာမျက်နှာတွင် နားထောင်ပါ။ Tor သီးသန့် အသံသည် သာမန် ဘရောက်ဆာများတွင် မပေါ်ပါ။

      

    


    

      
လေလှိုင်းပေါ် မတက်မီ
သင့်ဌာန အကြောင်း ရှင်းလင်းချက်။

      
Q-Cast သည် အင်တာနက်မရှိဘဲ အလုပ်လုပ်သလား။
မလုပ်ပါ။ Q-Cast သည် Tor အပါအဝင် အင်တာနက်ပေါ်တွင် stream လုပ်သည်။ ကွန်ရက်ပြင်ပတွင် RadioBridge သို့မဟုတ် LoRa ကို ၎င်းတို့၏ ရေဒီယို hardware ဖြင့် သုံးပါ။

      
ကမ္ဘာလုံးက ကျွန်ုပ်၏ GPS တည်နေရာကို ဖော်ပြသလား။
မဖော်ပြပါ။ Q-Cast သည် သင့် GPS ကို မဖတ်ပါ။ နေရာကို သင်ကိုယ်တိုင် ရွေးပြီး ဌာန အသေးစိတ်နှင့် ထိုနေရာသည် public ဖြစ်သည်။

      
ကျွန်ုပ်၏ ဌာနကို Tor သီးသန့် ထားနိုင်သလား။
ထားနိုင်သည်။ Tor မှတစ်ဆင့် ထုတ်လွှင့်ပြီး ထုတ်ဝေပါ။ စာရင်းသွင်းခြင်းက relay ကို သင့်အသံ open web ပေါ် တင်ခွင့် မပေးပါ။

      
ကျွန်ုပ်၏ ဌာနသည် နားထောင်သူ အနည်းငယ်ထက် ကြီးထွားနိုင်သလား။
ရနိုင်သည်၊ repeater သို့မဟုတ် Icecast ဆာဗာမှတစ်ဆင့်။ Direct mode က နားထောင်သူ သုံးဦးကို ဝန်ဆောင်သည်။ Q-P1NG က အခမဲ့ အကန့်အသတ်မဲ့ hosting မပေးပါ။
