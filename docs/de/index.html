        01
        
Stimmeffekte

        
Ghost, Interview, Robot, Shadow, Studio, angewandt auf dem Telefon. Ghost ist fail-closed: kein Effekt, kein Senden.

      

      

        02
        
Whisper-Diktat

        
Sprechen, Text bekommen: Whisper transkribiert auf dem Gerät. Die Aufnahme bleibt auf dem Telefon.

Vorlesestimmen

        
Kokoro liest Text mit natürlichen italienischen und englischen Stimmen vor, offline, auf dem Telefon.

      

      

        04
        
Prüfschritt

        
Hör sie vor dem Senden ab. Füge ein Whisper-Transkript hinzu (Pro), dann bearbeite oder lösche es.
