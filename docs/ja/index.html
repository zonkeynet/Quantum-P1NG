検索、絞り込み、失効

                
優先度や確認数で報告を絞り込めます。各報告は、TTL が切れるか解除されると地図から消えます。

              

            

          


          
          

            

              

                
              

              
1. 地図とテーマ

              
レイヤーで、インストール済みの PMTiles パックかオンラインのソースを選び、7 つのテーマから 1 つを選択：

              
    
                
  • タクティカル：落ち着いた緑、暖色のルート。
    • 
                
  • 危機：暗い背景、警告を最前面に。
    • 
                
  • ナイト：まぶしさを抑えた青黒。
    • 
                
  • OLED：真の黒で、目立たずに使える。
    • 
              

            


            

              

                
              

              
2. おおよその位置

              
報告を送る前に精度を設定：

              
    
                
  • おおよそ（既定）：小数点以下 3 桁、約 111 m（0x02 APPROXIMATE_LOCATION）。それでもエリアから身元が割れることがあります。
    • 
                
  • 正確：GPS の完全な精度。先に、その場所と誰が見るかを確認してください。
    • 
              

            


            

              

                
              

              
3. 5 ステップの報告ウィザード

              
新しい報告をタップし、次に：

              
    
                
  1. 種類：26 の危険コード。
    2. 
                
  2. 深刻度：1〜5。
    3. 
                
  3. 半径と TTL：例：500 m、最長 30 日。
    4. 
                
  4. 位置：GPS、長押し、または WGS84。
    5. 
                
  5. ルート：Tor チャット、Bluetooth、Wi-Fi。Pro では LoRa、VHF も。
    6. 
              

            


            

              

                
              

              
4. 検索と失効

              
受け取った報告を整理：

              
    
                
  • 検索と絞り込み：優先度、独立した確認、支援で。報告は主張であって、証拠ではありません。
    • 
                
  • 自動失効：報告は TTL が切れるか、解除・取り消しされると地図から消えます。
    •

Q-Cast はインターネットなしで使えますか？
いいえ。Q-Cast は Tor を含むインターネットで配信します。オフグリッドなら、RadioBridge か LoRa を無線機器とともに使ってください。
